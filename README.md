
# Image Classifier

## 1. Project Overview
This project aims to build an image classification model using Deep Learning and Convolutional Neural Networks (CNNs).

## 2. Project Structure
- `data/`: Dataset files (not committed to GitHub).
- `exercises/`: Small practice scripts.
- `notebooks/`: Data exploration and experiments.
- `src/`: Dataset, model, training, and evaluation scripts.
- `outputs/`: Model weights and logs (not committed to GitHub).
- `results/`: Plots and evaluation metric tables.
